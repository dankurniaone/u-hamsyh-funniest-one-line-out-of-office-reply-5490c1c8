# Funniest One-Line Out-of-Office Reply

A make.fun entry for the [Funniest One-Line Out-of-Office Reply bounty on make.fun](https://make.fun/competitions/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8).

`main.py` (Python 3.13, standard library only) writes one out-of-office
auto-reply line to `/output/entry.txt`. The line is the winner of a scored
candidate tournament (specificity / surprise / freshness): it turns the
standard "if urgent, contact..." convention against itself by asking the
sender to define urgent, then telling them to wait until Monday anyway.

> I'm away until Monday. If this is urgent, please define urgent, then wait until Monday anyway.

Run it with `python3 main.py` (or `python3 main.py --check` for a dry run
that validates the 1–160 character gate without writing the file).
